    What's here

    Search a name you heard, or click the map. Areas fit inside each other, biggest to smallest: town › district › sub-district › neighbourhood › small area. Reykjavík has every level; the other towns mostly have neighbourhoods only.

    Icelandic words you'll hear

    Place words: hverfi = neighbourhood or area · borgarhluti = city district · bær = town (also farm) · sveitarfélag = municipality · póstnúmer = postal code

    Street words: gata = street · vegur = road · braut = big road · stígur = path or lane · stræti = street (mostly downtown) · torg = square

    Name parts: holt = hill · hlíð = slope · tún = field · nes = headland · vogur, vík = bay · dalur = valley · fell = mountain · höfn = harbour · mýri = marsh · ás = ridge · melur = gravel flat

    Directions: vestur = west · austur = east · norður = north · suður = south · efra = upper · neðra = lower · gamli = old · nýi = new

    Why names change: Icelandic adds endings. “Holtin” means “the hills”, i.e. the Holt area, and “í Holtunum” means “in Holt”. Likewise Hlíðarnar, “á Völlunum” (Vellir), “í Vesturbænum” (Vesturbær). Search understands these forms.

    About the data

    Reykjavík districts, sub-districts and neighbourhoods: official boundaries from Reykjavíkurborg open data (lukrgatt.reykjavik.is).

    Kópavogur, Garðabær, Hafnarfjörður, Mosfellsbær: OpenStreetMap neighbourhood boundaries. Coverage varies; some areas show as named points only.

    Postal codes: approximate. Built from about 47,000 OpenStreetMap address points, each tagged with its postal code, then turned into areas and clipped to land and to municipality borders. Edges can be off by about one street.

    Pronunciations: computer-generated Icelandic speech for every place, postal code and street (Piper TTS, “Ugla” voice trained on the Talrómur corpus, CC BY 4.0), slowed slightly. Close, but not a native speaker; Forvo has real recordings for many names. The sound files live in the _assets/audio folder next to this page.

    Background maps need no API key. Map data © OpenStreetMap contributors (ODbL). Data built 2026-11-19.
